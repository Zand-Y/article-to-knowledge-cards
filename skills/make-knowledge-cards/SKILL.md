# 知识卡片生成

把用户粘贴的文章，或本地 Markdown / 纯文本文件，转换成一组用于复习的知识卡片。

## 适用范围

- 支持：用户直接粘贴的文本；本地 `.md`、`.txt` 文件（读取文件并提取正文）。
- 不支持：网页抓取、PDF、Anki、图形界面。用户要求这些时，说明暂不支持，并请其改为粘贴文本或提供 `.md`/`.txt` 文件。

## 输出格式

直接输出 Markdown 卡片列表。目标 5～8 张：内容不足时输出更少，内容过多时保留最重要的 8 张。每张卡片用以下结构：

### 卡片标题

- **核心知识**：一句话概括这个知识点。
- **简明解释**：用比原文更直白的话解释，保持准确，保留关键限定条件。
- **例子 / 自测**：原文有例子时改写成简洁例子；没有时，出一道答案可直接从卡片内容推出的自测问题。

## 提取规则

1. 只提取真正重要的知识：定义、核心概念、因果机制、规则、关键区别、反直觉事实。跳过寒暄、重复叙述的例子、元评论和细枝末节。
2. 一张卡片只讲一个知识点。一个段落含多个概念时拆成多张卡；同一概念在不同位置出现时合并成一张。
3. 删除重复内容。同一知识点多次出现，保留表述最完整、最准确的一次。
4. 不编造原文没有的信息。所有事实、数字、日期、结论都必须来自原文。没有例子时改用自测问题，但问题答案必须来自原文。
5. 不强行凑数量，也不超量堆叠。5～8 张是目标不是配额；原文只有 3 个重要知识点就输出 3 张，超过 8 个就只保留最重要的 8 个。
6. 标题短而具体，直接点明概念。
7. 卡片语言与原文一致，术语保留原文写法；保持简短，便于快速复习。
8. 对步骤类（教程、操作指南）内容，提炼背后的概念、关键命令与判断依据，而不是逐条照抄操作步骤。

## 流程

1. 获取正文：用户粘贴则直接用；给了文件路径则读取 `.md`/`.txt`。来源有多个时，以用户最后指明或最新的一条为准。
2. 通读全文，圈出关键知识点并去重。
3. 按重要性排序，为每个知识点写一张卡片。
4. 检查：一张卡一个点、已删重、没有原文不存在的内容、数量与内容量匹配。
5. 输出卡片列表，不加冗长开场或逐卡复述。
