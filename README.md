# make-knowledge-cards

一个 Codex Skill：把长文章或笔记自动提炼成结构统一的知识卡片，用于快速复习和自测。

## 解决什么问题

读长文、看教程或整理笔记时，重要知识点往往散落在各处。手动做知识卡片费时，还容易遗漏、重复，甚至补进原文没有的内容。`make-knowledge-cards` 自动完成提取和去重，把一篇文章变成一组可以直接复习的卡片。

## 主要功能

- 输入灵活：粘贴文章正文，或指向本地 Markdown（`.md`）/ 纯文本（`.txt`）文件。
- 标准卡片：每张卡片包含标题、核心知识、简明解释、例子或自测问题。
- 自动提炼：只保留真正重要的知识点，一张卡片只讲一个点，自动删除重复内容。
- 忠于原文：不编造原文没有的信息；原文没有例子时，改用答案可由卡片内容推出的自测题。
- 数量合理：目标 5～8 张；内容不足时不硬凑，内容过多时只保留最重要的 8 张。
- 步骤类内容：提炼背后的概念、关键命令与判断依据，而不是逐条照抄操作步骤。
- 明确边界：暂不支持网页抓取、PDF、Anki 和图形界面。

## 安装方法

本项目只包含一个 Skill 目录，由 `SKILL.md` 和 `agents/openai.yaml` 两个文件组成，无需安装脚本或依赖。

把整个 `skills/make-knowledge-cards` 目录复制到 Codex 的技能目录即可：

```bash
mkdir -p ~/.codex/skills
cp -r skills/make-knowledge-cards ~/.codex/skills/
```

如果设置了 `CODEX_HOME`，则复制到 `$CODEX_HOME/skills/`。

## 使用方法

1. 在 Codex 中调用 Skill：

   ```text
   $make-knowledge-cards
   ```

   也可以用自然语言，例如“把下面这篇文章转成知识卡片”。

2. 提供输入，二选一：

   - 直接粘贴文章正文；
   - 给出本地文件路径，例如 `/path/to/article.md` 或 `/path/to/notes.txt`。

3. Skill 读取正文后，输出 Markdown 卡片列表。

## 输入输出示例

输入（粘贴文本）：

```text
把下面的文字转成知识卡片：

光合作用分为光反应和暗反应。光反应需要光，发生在叶绿体类囊体膜上，产生氧气、ATP 和 NADPH。暗反应不直接需要光，利用 ATP 和 NADPH 把二氧化碳合成有机物。
```

输出：

```markdown
### 光合作用的两个阶段

- **核心知识**：光合作用分为需要光的光反应和不需要光的暗反应。
- **简明解释**：光反应依赖光；暗反应不直接依赖光，但要消耗光反应的产物。
- **自测**：光合作用哪个阶段需要光？

### 光反应的产物

- **核心知识**：光反应发生在叶绿体类囊体膜上，产生氧气、ATP 和 NADPH。
- **简明解释**：光能把水分解并放出氧气，同时生成后续合成所需的能量分子。
- **自测**：光反应释放哪种气体？产生哪两种能量分子？
```
